What is AST: https://en.wikipedia.org/wiki/Abstract_syntax_tree
- Data structure used to represent structure of program or code snippet.
- It is tree representation written in a formal language, each node denotes a construct occurring in the text
- Known as syntax tree


AST in NodeJS:
- In NodeJS, AST is used in JS really often, as template engines and typescript etc.
- If pp vuln exist in JS app, any AST can be inserted in the function by making it insert during Parser or Compiler process
- Here, can insert AST without proper filtering of input that has not been verified by lexer or Parser -> Give unexpected input to compiler
